# Third-party icon notices

Skit bundles a 77-icon subset generated from `@iconify/json` version `2.2.470`.
Only icon data required by the production module graph is copied into
`src/plugins/svgIcon/productIconCollections.ts`; the full Iconify JSON package is
not a runtime dependency.

This notice and the complete license texts are distributed with every production
build under `legal/`:

- `legal/THIRD_PARTY_NOTICES.txt`
- `legal/licenses/MIT.txt`
- `legal/licenses/APACHE-2.0.txt`
- `legal/licenses/OFL-1.1.txt`
- `legal/licenses/CC-BY-4.0.txt`

The repository copies the same files from `public/legal/` into `dist-prod/legal/`.
The production verifier checks their exact bytes and checksums before a Docker
image can be published.

## Material Design Iconic Font and Fontisto font terms

The two `zmdi` records come from Material Design Iconic Font by Sergey Kupletsky
(@zavoloklom), https://zavoloklom.github.io/material-design-iconic-font/.
The pinned Iconify metadata and upstream font headers identify OFL-1.1 for the
font. The complete SIL Open Font License 1.1 is in
`legal/licenses/OFL-1.1.txt`.

Fontisto collection metadata identifies its copied icon data as MIT. Fontisto's
font distribution also identifies the font under OFL; the production artifact
conservatively carries both complete texts.
